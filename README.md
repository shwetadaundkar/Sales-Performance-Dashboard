# Sales Performance Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze sales performance across different regions, products, and customer segments.

## Tools Used
- Power BI
- SQL
- Excel

## KPIs
- Total Sales
- Total Profit
- Profit Margin
- Sales by Region
- Top Products
- Monthly Sales Trend

## Key Insights
- Identified highest-performing regions.
- Analyzed top-selling products.
- Tracked monthly sales growth.
